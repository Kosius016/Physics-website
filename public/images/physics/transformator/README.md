# Снимки за урок 4.2 (трансформаторът и преносът)

Четирите снимки са локални WebP assets, оптимизирани до ширина 1600 px. На страницата се
зареждат през `next/image` и `components/LessonPhoto.tsx`; под всяка снимка се показват авторът,
страницата на оригинала и лицензът.

- Автор: Root FileSystem
- Оригинал: <https://commons.wikimedia.org/wiki/File:Dead-end_pylon_triple_400_kV_B%C4%83icoi_D_RO_2017.jpg>
